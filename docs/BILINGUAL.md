# Bilingual Rules

Edu Hub launches with two locales:

- `en-EG` — English, LTR
- `ar-EG` — Arabic, RTL

Current routes:

- `/en-eg/`
- `/ar-eg/`

Every public page should eventually have a corresponding page in both languages when the final content is available.

The HTML `lang` and `dir` attributes must match the active language. Canonical URLs and `hreflang` alternatives should point to the correct language versions.

Do not invent Arabic or English institution data. The owner will supply the final approved tables/content.
