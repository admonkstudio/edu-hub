# طلب بيانات — وزارة التربية والتعليم والتعليم الفني / EMIS

**الموضوع:** طلب نسخة بيانات آلية حديثة من دليل المدارس المصرية / نظام معلومات إدارة التعليم (EMIS)

السادة/ وزارة التربية والتعليم والتعليم الفني

تحية طيبة وبعد،

نحن نعمل على مشروع **Edu Hub**، وهو مشروع معلوماتي يهدف إلى بناء دليل تعليمي شامل وموثوق للمؤسسات التعليمية في جمهورية مصر العربية، مع الحفاظ على مصدر كل معلومة وتاريخ الحصول عليها، وعدم نشر أي بيانات غير متاحة للعامة أو غير مصرح باستخدامها.

نرجو التكرم بإتاحة **نسخة حديثة كاملة وقابلة للمعالجة آليًا** من البيانات الصفّية التي يعتمد عليها **دليل المدارس المصرية** / نظام معلومات إدارة التعليم (EMIS)، للعام الدراسي **2025/2026** أو أحدث نسخة متاحة.

يفضل تسليم البيانات بصيغة CSV UTF-8 أو XLSX أو JSON أو أي صيغة آلية مناسبة، مع الاحتفاظ بجميع الأعمدة الأصلية المتاحة في النظام، وعدم اختصار التصدير في مجموعة حقول يحددها المشروع مسبقًا.

ونرجو، متى كانت الحقول متاحة في المصدر، تضمين ما يلي:

- الكود/المعرف الأصلي الفريد للمدرسة؛
- اسم المدرسة بالعربية والإنجليزية إن وجد؛
- المحافظة والمديرية والإدارة التعليمية والمركز/القسم؛
- العنوان وبيانات الموقع الجغرافي؛
- نوع وتصنيف المدرسة؛
- المراحل التعليمية؛
- نوع الطلاب (بنين/بنات/مشترك)؛
- لغة الدراسة أو النظام/المنهج عندما يكون مسجلاً؛
- تبعية/ملكية/إدارة المدرسة؛
- حالة التشغيل أو النشاط؛
- أرقام الهاتف وبيانات الاتصال العامة؛
- الإحداثيات أو معرفات الخرائط إن وجدت؛
- رابط الموقع أو الصفحة العامة إن وجد؛
- بيانات المصروفات المنشورة في دليل المدارس، متى كانت قابلة لإعادة الاستخدام؛
- العام الدراسي/تاريخ سريان البيانات؛
- تاريخ آخر تحديث؛
- أي جداول أكواد أو تصنيفات لازمة لفهم القيم المشفرة.

القائمة السابقة توضيحية فقط؛ ونفضل استلام **جميع الحقول الأصلية المتاحة** في قاعدة البيانات/الدليل.

كما نرجو إرفاق، إن أمكن:

1. قاموس البيانات وتعريف الحقول؛
2. جداول الأكواد والتصنيفات؛
3. عدد السجلات في النسخة المرسلة؛
4. تاريخ الاستخراج والفترة الدراسية التي تمثلها؛
5. توضيح ما إذا كانت المدارس المغلقة أو غير النشطة مشمولة؛
6. توضيح ما إذا كان السجل يمثل مدرسة أم فرعًا/حرمًا/وحدة أخرى؛
7. أي شروط أو قيود خاصة بإعادة نشر الحقول المعروضة أصلًا للجمهور من خلال دليل المدارس المصرية.

سيتم الاحتفاظ بالملف الأصلي كما تم استلامه، مع تسجيل مصدره وتاريخ الاستلام وبصمة SHA-256، ولن يتم تعديل السجلات الأصلية أو دمجها قبل مرحلة منفصلة لمطابقة الهويات ومراجعة التكرارات.

إذا لم تكن الجهة المختصة باستلام هذا الطلب هي جهة المخاطبة الحالية، نرجو التكرم **بتحويل الطلب إلى الإدارة العامة للمعلومات والحاسب الآلي / الجهة المسؤولة عن EMIS ودليل المدارس المصرية** أو تزويدنا ببيانات التواصل الصحيحة.

وتفضلوا بقبول فائق الاحترام والتقدير.

- لا ترسل أي أسرار أو بيانات شخصية غير عامة مع الطلب.
